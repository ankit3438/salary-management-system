# Salary Management Frontend - Angular 22

This is a self-contained Angular 22 starter for the Salary Management System. It uses in-memory demo data so the UI can run before the Spring Boot APIs are connected.

Run:
npm install
npm start

Open http://localhost:4200

Routes:
- /dashboard
- /employees
- /employees/new
- /employees/:id
- /employees/:id/edit
- /employees/:employeeId/salary/add
- /employees/:employeeId/salary
